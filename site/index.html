Everything included

Five products. One process.

The orchestrator, the serverless runtime, the analytics engine, the notebook, and the agent interface usually arrive as five vendors and a Kubernetes cluster. Loom ships them as a single binary with SQLite inside.

Polyglot DAGs

Python, TypeScript, and JavaScript tasks in one graph — a Python task's output becomes a TS task's input. Parallel layers, retries, timeouts, cycle-validated at deploy.

Warm pools or sandboxes

Interpreters stay alive between tasks — 36 ms → 1.2 ms per Python invoke. When trust matters more than latency, flip one env var to run each task in a locked-down container or a microVM (Kata / Firecracker).

Streaming everything

Run states, task logs, and metrics broadcast over SSE. Ingestion consumes NDJSON chunk-by-chunk at ~780 MB/s — gigabyte payloads never sit in memory.

SQL on a Rust engine

Every dataset is a table. Embedded Polars aggregates 1.8M rows in ~250 ms — from the API, the SDKs, notebook cells, or loom.query() inside any task. Postgres, ClickHouse & chDB connectors included.

Serverless functions

Deploy a handler in either language, invoke over HTTP with JSON or stream logs + result via SSE. ~775 invocations/s on a dev container.

Notebooks

Observable-style executable documents: markdown with images, code cells in any runtime with data-aware autocomplete (it knows the fields of the cell above), SQL cells, and nine chart marks — bar, line, area, scatter, donut, histogram, radar, min/avg/max bands — with a colour picker. Publish read-only with one click.

Agent-native (MCP)

A built-in Model Context Protocol server with 15 tools: agents compose workflows, execute code, query data, create notebooks, and read results — a self-correcting loop out of the box. claude mcp add loom … and go.

One password. Publish what you want.

Set LOOM_PASSWORD and the API, MCP, and console are locked. Hit Publish on a notebook and anyone with the link can read it — cells, outputs, charts — but nothing public can execute or edit. Unpublish any time.

Zero infrastructure

One 67 MB binary, one SQLite file (WAL), one volume. 16 MB RAM idle, 0% CPU. Deploys on a $4 VPS, docker compose, or Coolify in three clicks.

Developer experience

Define in your language. Run on Rust.

pipeline.pypython sdk · zero deps
from loom_sdk import LoomClient, Flow, task

@task
def extract(params, inputs):
    return {"values": list(range(params["n"]))}

@task(depends_on=[extract], retries=2)
def total(params, inputs):
    return sum(inputs["extract"]["values"])

client = LoomClient("http://localhost:7420")
wf = client.deploy(Flow("sum", params={"n": 100},
                        tasks=[extract, total]))
run = client.trigger(wf["id"], wait=True)
# run["state"] == "completed" · 7 ms later
inside any taskrust engine bindings
import loom   # injected into every worker

def handler(params, inputs):
    rows = loom.query("""
      SELECT zone, AVG(value) AS avg_v
      FROM telemetry GROUP BY zone
    """)  # 1.8M rows, ~250ms, in Rust
    loom.ingest("zone-aggregates", rows)
    return {"zones": len(rows)}
